# StayMate 🏠

StayMate is an Android application designed to help students, tenants, property owners, and roommates connect on a single platform. The app simplifies the process of finding PGs, rental properties, and compatible roommates while providing secure communication and booking features.

## Features

### Tenant Features

* User Registration and Login
* Browse Available Properties
* Search and Filter Properties
* Save Favorite Properties
* View Property Details
* Book Properties
* Chat with Property Owners
* Manage Profile and Settings

### Owner Features

* Add New Properties
* Manage Property Listings
* View Booking Requests
* Accept or Reject Requests
* Chat with Tenants
* Manage Owner Profile

### Roommate Finder

* Create Roommate Posts
* Browse Roommate Listings
* View Roommate Details
* Connect with Potential Roommates

### Communication

* Real-Time Chat
* Notifications using Firebase Cloud Messaging (FCM)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ayushihirani18/StayMate.git
   ```

2. Open the project in Android Studio.

3. Connect Firebase using your own Firebase project configuration.

4. Sync Gradle files.

5. Build and run the application.
